# 档案提取模式 AI 智能训练系统

## 需求背景

项目不使用预设题库系统，所有内容由 AI 根据学员档案和训练目标动态生成。档案提取模式需要实现完整的 AI 智能训练流程，包括诊断测试、任务规划、引导式训练和综合考试。

## 核心理念

**类似 Kiro 的 Spec 模式**：AI 不是简单出几道题，而是：
1. 先通过诊断测试了解学员当前水平
2. 根据测试结果生成详细的学习计划（类似 spec 文档）
3. 按计划进行系统化的引导式训练
4. 最后通过大型综合考试验收学习成果

## 完整训练流程

### 阶段 1：任务创建（家长端）
1. 家长选择"档案提取模式"
2. 选择学员（自动提取完整档案）
3. 填写训练目标（如"备战初二上学期物理期末考试"）
4. 设置诊断测试题目数量（默认 10 题，范围 5-20）
5. 提交创建任务

### 阶段 2：诊断测试（学员端）
**目标**：通过测试了解学员当前知识掌握情况

6. 学员进入训练舱
7. 创建训练会话，phase = 'DIAGNOSTIC_TEST'
8. AI 逐题生成诊断测试题目
9. 学员作答
10. 提交答案，AI 判断对错
11. AI 生成下一道诊断题
12. 重复 9-11 直到完成所有诊断题目

**诊断测试特点**：
- 题目覆盖训练目标相关的各个知识点
- 难度从易到难，全面评估学员水平
- 记录答题情况、用时、错误类型

### 阶段 3：AI 分析与计划生成
**目标**：AI 深度分析诊断结果，生成详细的学习计划

13. 诊断测试完成后，进入 phase = 'PLANNING'
14. AI 分析诊断测试结果：
    - 统计正确率、错题分布
    - 识别薄弱知识点
    - 评估学员学习风格
    - 结合档案信息（年级、教材版本、学习基础）
15. AI 生成完整的训练计划（类似 spec 文档）：
    - **学习目标分解**：将训练目标拆分为多个子目标
    - **知识点清单**：列出需要掌握的所有知识点
    - **训练阶段规划**：
      - 基础巩固阶段（针对薄弱点）
      - 能力提升阶段（进阶训练）
      - 综合应用阶段（实战演练）
    - **每个阶段的详细内容**：
      - 学习重点
      - 练习题数量和类型
      - 预计用时
      - 验收标准
    - **综合考试规划**：
      - 考试范围
      - 题目数量（20-50 题，类似期末考）
      - 难度分布
      - 及格标准
16. 显示训练计划给学员确认
17. 学员点击"开始训练"

### 阶段 4：引导式训练（学员端）
**目标**：按照 AI 生成的计划进行系统化训练

18. 进入 phase = 'GUIDED_TRAINING'
19. 按计划的阶段顺序进行训练：
    - **基础巩固阶段**：
      - AI 针对薄弱知识点出题
      - 每题都有详细讲解
      - 答错后 AI 引导思考，可重做
    - **能力提升阶段**：
      - 难度逐步提升
      - 综合性题目
      - AI 提供解题思路指导
    - **综合应用阶段**：
      - 实际应用场景题目
      - 跨知识点综合题
      - 培养解决实际问题能力
20. 每个阶段完成后，AI 生成阶段小结
21. 学员可随时与 AI 助手对话求助

### 阶段 5：综合考试（学员端）
**目标**：全面验收学习成果，类似期末大考

22. 所有训练阶段完成后，进入 phase = 'FINAL_EXAM'
23. AI 生成综合考试：
    - **题目数量**：20-50 题（根据训练目标复杂度）
    - **题型多样**：选择题、填空题、解答题
    - **难度分布**：
      - 基础题 40%（巩固基础）
      - 中等题 40%（能力检验）
      - 难题 20%（拔高挑战）
    - **知识点覆盖**：涵盖所有训练过的知识点
    - **时间限制**：根据题目数量设置合理时间
24. 学员答题（不能求助 AI，模拟真实考试）
25. 提交考试

### 阶段 6：报告生成与任务完成
**目标**：生成详细的训练报告，总结学习成果

26. 进入 phase = 'COMPLETED'
27. AI 生成完整训练报告：
    - **诊断测试分析**：初始水平评估
    - **训练过程回顾**：各阶段表现
    - **综合考试成绩**：
      - 总分和正确率
      - 各知识点得分
      - 与诊断测试对比（进步情况）
    - **薄弱点分析**：仍需加强的内容
    - **学习建议**：后续学习方向
    - **积分奖励**：根据表现发放积分
28. 显示报告，任务完成
29. 任务状态更新为 COMPLETED

## 技术方案

### 阶段 1：训练会话启动优化

**目标**：档案提取模式成功创建训练会话，不依赖题库

**实现**：
1. ✅ 已完成：`studentTrainingService.ts` 中检测 `profileBased` 模式
2. ✅ 已完成：跳过题库查询，创建空题目列表的训练会话
3. ✅ 已完成：设置 `totalSteps` 为配置的题目数量

**验收标准**：
- 学员点击进入训练舱不报错
- 成功创建训练会话
- 后端日志显示"档案提取模式：将由 AI 动态生成题目"

### 阶段 2：AI 动态生成第一道题

**目标**：训练舱加载时，AI 根据档案信息生成第一道题

**后端实现**：

1. **新增 AI 生成题目服务方法**
   - 文件：`backend/src/services/aiQuestionGeneratorService.ts`
   - 方法：`generateQuestion(taskConfig, studentProfile, questionNumber)`
   - 输入：任务配置、学员档案、题目序号
   - 输出：题目对象（题干、选项、答案、解析）

2. **修改训练控制器**
   - 文件：`backend/src/controllers/studentTrainingController.ts`
   - 新增方法：`getNextQuestion(sessionId)`
   - 逻辑：
     - 检查会话状态
     - 判断是否为档案提取模式
     - 调用 AI 生成题目服务
     - 返回题目数据

3. **AI Prompt 设计**
   - 包含学员档案完整信息
   - 包含训练目标
   - 包含当前题目序号和总题数
   - 要求 AI 生成符合年级和教材版本的题目
   - 返回 JSON 格式：题干、选项、正确答案、解析

**前端实现**：

1. **修改训练舱组件**
   - 文件：`frontend/src/pages/student/TrainingCabin.tsx`
   - 检测档案提取模式
   - 调用新的获取题目接口
   - 显示 AI 生成的题目

2. **加载状态优化**
   - 显示"AI 正在为你生成题目..."
   - 添加加载动画
   - 超时处理（30秒）

**验收标准**：
- 进入训练舱后，中间栏显示"AI 正在为你生成题目..."
- 5-10秒内显示第一道题目
- 题目包含题干、选项、正确答案
- 题目符合学员年级和教材版本

### 阶段 3：题目提交和下一题生成

**目标**：学员提交答案后，AI 生成下一道题

**后端实现**：

1. **修改答案提交逻辑**
   - 文件：`backend/src/services/studentTrainingService.ts`
   - 方法：`submitAnswer(sessionId, answer)`
   - 档案提取模式：不查询题库答案，由 AI 判断对错
   - 更新会话进度
   - 触发生成下一题

2. **AI 判断答案**
   - 将学员答案发送给 AI
   - AI 判断对错并给出解析
   - 返回判断结果和详细反馈

**前端实现**：

1. **答案提交流程**
   - 提交答案
   - 显示 AI 判断结果
   - 显示解析和反馈
   - 点击"下一题"按钮
   - 加载下一道题

**验收标准**：
- 提交答案后，AI 正确判断对错
- 显示详细的解析和反馈
- 点击"下一题"后，AI 生成新题目
- 题目序号正确递增

### 阶段 4：训练完成和报告生成

**目标**：完成所有题目后，生成训练报告

**后端实现**：

1. **完成训练逻辑**
   - 文件：`backend/src/services/studentTrainingService.ts`
   - 方法：`completeTraining(sessionId)`
   - 统计答题情况
   - 调用 AI 生成训练报告
   - 更新任务状态

2. **AI 生成报告**
   - 分析答题数据
   - 生成学习建议
   - 标注薄弱知识点
   - 推荐后续学习方向

**验收标准**：
- 完成最后一题后，显示训练完成
- 生成完整的训练报告
- 报告包含正确率、薄弱点、学习建议
- 任务状态更新为已完成

### 阶段 5：题目数量自定义

**目标**：创建任务时允许设置题目数量

**前端实现**：

1. **任务配置中心**
   - 文件：`frontend/src/pages/parent/TaskConfigCenter.tsx`
   - 添加"题目数量"输入框
   - 默认值：10
   - 范围：5-30
   - 档案提取模式和自定义模式都显示

**后端实现**：

1. **任务创建服务**
   - 文件：`backend/src/services/parentTaskService.ts`
   - 接收 `questionCount` 参数
   - 保存到任务配置中
   - 创建训练会话时使用该值

**验收标准**：

- 可以设置 5-30 之间的任意值
- 训练时按设置的数量生成题目
- 进度显示正确（如 3/20）

## API 设计

### 1. 获取下一道题目
```
GET /api/student/training/next-question/:sessionId

Response:
{
  success: true,
  data: {
    questionNumber: 1,
    totalQuestions: 10,
    question: {
      stem: "题干内容",
      options: ["A选项", "B选项", "C选项", "D选项"],
      type: "single_choice"
    }
  }
}
```

### 2. 提交答案（档案提取模式）
```
POST /api/student/training/submit-answer/:sessionId

Request:
{
  answer: "A",
  questionNumber: 1
}

Response:
{
  success: true,
  data: {
    correct: true,
    correctAnswer: "A",
    explanation: "解析内容",
    feedback: "AI 反馈"
  }
}
```

## 技术栈

- **AI 服务**：使用现有的 AI 服务配置（OpenAI/Claude/DeepSeek 等）
- **Prompt 工程**：设计专门的出题和判题 Prompt
- **状态管理**：训练会话状态机
- **错误处理**：AI 调用失败的降级方案

## 风险和挑战

1. **AI 响应时间**：生成题目可能需要 5-10 秒
   - 解决：显示友好的加载提示
   - 优化：缓存常见题型

2. **AI 生成质量**：题目质量可能不稳定
   - 解决：精心设计 Prompt
   - 优化：添加题目质量检查

3. **成本控制**：每道题都调用 AI，成本较高
   - 解决：使用成本较低的模型
   - 优化：批量生成题目

## 后续优化

1. **题目缓存**：预生成部分题目，减少等待时间
2. **难度自适应**：根据答题情况动态调整难度
