# 试卷转换与入库工作流

> 两步操作：**转换** → **入库**。脚本自动处理 PDF/DOCX 解析、公式 OCR、数据库写入。

---

## 目录结构

```
DataWork/
├── SourceData/          ← 放试卷源文件（PDF/DOCX）
│   ├── 数学/
│   │   ├── 专题01 xxx(原卷版).pdf
│   │   ├── 专题01 xxx(解析版).docx
│   │   └── ...
│   ├── 物理/
│   ├── 英语/
│   └── ...
├── OutputData/          ← 转换产物（自动生成，无需手动管理）
├── 试卷转换.*           ← 第一步：转换脚本（4种终端格式）
├── 试卷入库.*           ← 第二步：入库脚本（4种终端格式）
└── .env                 ← 环境变量配置（可选）
```

---

## 快速开始

### 1. 准备源数据

将试卷 PDF/DOCX 文件按学科放入 `SourceData/` 子目录：

```
SourceData/数学/    ← 数学试卷
SourceData/物理/    ← 物理试卷
SourceData/英语/    ← 英语试卷
```

**文件要求**：
- 按学科建子目录，目录名即学科名
- 原卷版和解析版放在同一目录下
- 支持 PDF、DOCX 格式

### 2. 第一步：转换

运行转换脚本，将 PDF/DOCX 转为结构化 JSON：

```bash
# Linux / macOS / Git Bash
bash 试卷转换.sh 数学          # 转换单个学科
bash 试卷转换.sh --all         # 转换全部学科

# Windows CMD（双击或命令行）
试卷转换.bat 数学
试卷转换.bat                   # 无参数自动扫描全部学科

# Windows PowerShell
.\试卷转换.ps1 数学
.\试卷转换.ps1 -All

# Fish Shell
fish 试卷转换.fish 数学
fish 试卷转换.fish --all
```

**产物**：`OutputData/progress-{学科}.json`

### 3. 第二步：入库

转换完成后，运行入库脚本将数据写入数据库：

```bash
# Linux / macOS / Git Bash
bash 试卷入库.sh 数学          # 入库单个学科
bash 试卷入库.sh --all         # 入库全部学科
bash 试卷入库.sh --dry         # 只检查不写库（推荐先跑一次）

# Windows CMD
试卷入库.bat 数学
试卷入库.bat

# Windows PowerShell
.\试卷入库.ps1 数学
.\试卷入库.ps1 -All

# Fish Shell
fish 试卷入库.fish 数学
fish 试卷入库.fish --all
```

## 飞桨 PaddleOCR 配置（推荐）

转换脚本支持飞桨 PaddleOCR API，可将 PDF 中的数学/物理公式自动转为 LaTeX，大幅提高公式识别质量。

### 获取 API Key

1. 访问 https://paddleocr.aistudio.com.cn/
2. 注册并申请 API Key
3. **日额度：20000 页**，足以应对日常使用

### 配置方式

**方式一：脚本交互输入（推荐）**

首次运行转换脚本时，如果未检测到 API Key，脚本会提示输入：

```
🔑 飞桨 PaddleOCR API Key 未配置
   获取地址: https://paddleocr.aistudio.com.cn/
   日额度: 20000 页（推荐使用）

   请输入 API Key（留空跳过）: xxxxxxxx
   ✅ 已保存到 .env
```

输入后自动保存到 `.env` 文件，后续运行无需重复输入。

**方式二：手动配置**

复制 `.env.example` 为 `.env`，填入 API Key：

```bash
cp .env.example .env
# 编辑 .env，填入 PADDLE_API_KEY=你的key
```

> **注意**：不配置 API Key 也可运行，但数学/物理/化学/生物学科的公式 OCR 步骤会被跳过，公式可能显示为乱码。

## 可选参数

### 转换脚本

| 参数 | 说明 |
|------|------|
| `--limit N` | 最大处理文件数 |
| `--retry-errors` | 重试之前失败的文件 |
| `--ocr-only` | 仅处理扫描件 |

```bash
bash 试卷转换.sh 数学 --limit 10    # 只转前10个文件
bash 试卷转换.sh --all --retry       # 重试所有失败文件
```

### 入库脚本

| 参数 | 说明 |
|------|------|
| `--dry` | 只检查不写库 |

```bash
bash 试卷入库.sh 数学 --dry    # 检查转换产物，不写库
```

## 产物说明

| 文件 | 用途 |
|------|------|
| `progress-{学科}.json` | 转换产物（结构化题目数据） |
| `progress-formula-{学科}.json` | 公式 OCR 进度 |
| `ocr-usage.json` | OCR 额度使用统计 |
| `progress-import.json` | 入库进度 |

所有产物均在 `OutputData/` 下，**不入 Git 仓库**。

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 公式显示乱码 | 配置飞桨 API Key 后重跑转换 |
| 选项重复/错位 | 检查源文件格式，或重试失败文件 |
| 入库跳过某学科 | 删除 `OutputData/progress-import.json` 中对应条目 |
| 未找到 Node.js | 安装 Node.js 并确保 `node` 在 PATH 中 |
| Python 相关功能不可用 | 安装 `pymupdf`、`requests`（扫描件 OCR 需要） |
