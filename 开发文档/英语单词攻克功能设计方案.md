# 英语单词攻克（AI 词汇老师）— 功能设计方案

> 目标：专项攻克任务新增**英语单词独立版块**，导入初中 3500 词 PDF 为固定数据，支持听写/默写两种模式 + AI 词汇老师实时出短语填空题加深记忆，单词按艾宾浩斯曲线安排复习，独立错题集记录单词错误频率。



***

## 一、整体架构

```
┌─────────────── 学员端（家长可建任务） ───────────────┐
│ 任务中心 → 专项攻克 → 【英语单词】独立版块             │
│   ├─ 新建单词任务（模式/阶段/抽词/组数/间隔）          │
│   └─ 训练舱（WordTraining 页）                        │
│        ├─ 听写模式：edge-tts 按组发音 → 输入提交       │
│        ├─ 默写模式：按组显示中文释义 → 输入提交        │
│        └─ 每完成 N 词 → LLM 短语填空（加深记忆）       │
└──────────────────────────────────────────────────────┘
         │                     │                    │
    Word 表（词库）      WordSession（会话）    edge-tts 微服务
    WordMistake（错词）                        （services/word-tts）
```

## 二、数据层设计（Prisma 新增 3 张表）

### 2.1 Word 词库表（固定数据，导入后只读）

```prisma
model Word {
  id        String  @id @default(uuid())
  stage     String  // '小学' | '初中' | '高中'
  word      String  // 单词（唯一 per stage? 单词跨阶段可能重复 → 复合唯一）
  phonetic  String  @default("")   // 音标（PDF 提取，破损可留空）
  meaning   String  // 中文释义
  sourceDay Int?    // 所属天（PDF 为「15 天」，可选保留）
  @@unique([stage, word])
}
```

- **导入方式**：`backend/seed-data/words-stage-初中.json`（清洗后约 1487 条，几十 KB，**提交仓库**）+ `backend/scripts/import-words.mjs`（幂等 upsert）。小学/高中后续再生成对应 JSON 追加。

- 词表 JSON 入库（不是 PDF 文件）——文本小、可版本管理。

### 2.2 WordMistake 单词错题集（记录错误频率 + 艾宾浩斯状态）

```prisma
model WordMistake {
  id           String   @id @default(uuid())
  studentId    String
  wordId       String
  wrongCount   Int      @default(0)   // 累计错误次数
  correctCount Int      @default(0)   // 累计正确次数
  level        Int      @default(0)   // 掌握层级 0=未学过 1..7（艾宾浩斯档位）
  lastWrongAt  DateTime?
  nextReviewAt DateTime? // 下次复习时间（艾宾浩斯计算）
  @@unique([studentId, wordId])
}
```

- **独立于现有错题本**：现有 `Answer`/错题本管"题目"错题；`WordMistake` 管"单词"错误，两者不混（短语填空题也不进这里——见 §五）。

### 2.3 WordSession 单词训练会话

```prisma
model WordSession {
  id        String   @id @default(uuid())
  taskId    String   // 关联 Task（specialType='WORD'）
  studentId String
  mode      String   // 'DICTATION' | 'SPELLING'
  stage     String
  wordIds   Json     // 本次会话单词顺序（抽词结果）
  index     Int      @default(0)      // 当前已训练到第几个
  status    String   @default('IN_PROGRESS') // IN_PROGRESS | COMPLETED
  total     Int      // 本次会话目标词数（默认 20）
  createdAt DateTime @default(now())
}
```

### 2.4 任务配置（复用 Task，specialType 加 WORD）

`Task.config` 新增单词任务配置：

```json
{
  "mode": "DICTATION" | "SPELLING",   // 听写 / 默写
  "stage": "初中",                      // 小学 / 初中 / 高中
  "orderMode": "SEQUENCE" | "RANDOM",  // 顺序 / 随机抽词
  "groupSize": 2,                      // 每组单词数 1/2/3/4/5
  "intervalSec": 5,                    // 每组间隔（秒，手动输入）
  "roundSize": 20,                     // 每轮听写/默写词数（触发短语填空）
  "aiTeacherId": "…"                   // 固定为「词汇老师」指令 id
}
```

> 家长端/学员端创建时：老师选项锁定为"AI 词汇老师"（不展示其他学科老师）。

## 三、接口设计（学员端）

| 接口                                          | 说明                                                            |
| ------------------------------------------- | ------------------------------------------------------------- |
| `GET /student/word-bank/stages`             | 词库阶段列表 + 各阶段词数（小学/初中/高中）                                      |
| `POST /student/word-task/start/:taskId`     | 创建会话并返回第一组单词（按抽词规则：待复习错词优先 + 新词，见 §六）                         |
| `POST /student/word-task/group/:sessionId`  | 提交上一组结果 + 返回下一组（body 传本组单词作答数组）                               |
| `POST /student/word-task/submit/:sessionId` | 单组内逐词提交（记录 WordMistake，更新艾宾浩斯）                                |
| `POST /student/word-task/cloze/:sessionId`  | **完成 roundSize 个词后**调用 AI 词汇老师出短语填空题（实时、不入库）                  |
| `POST /student/word-task/cloze/check`       | 短语填空题答案判定（LLM 或规则，实时）                                         |
| `POST /student/word-task/tts`               | 听写发音：`{word}` → 调 `services/word-tts` 返回 mp3（edge-tts）；可批量预生成 |
| `GET /student/word-task/mistakes?stage=`    | 单词错题集（错误频率排序，供复习/展示）                                          |

## 四、edge-tts 发音方案

- 新增 Python 微服务 `services/word-tts`（pip 安装 `edge-tts`，仿照现有 services/formula-verify 的端口/启动方式）：

  - `POST /tts { text, voice? }` → 返回 mp3 音频（edge-tts 微软免费 TTS，支持美音/英音）

  - 听写场景**按组批量生成**：`POST /tts/batch { words: [...] }` → 按组间隔拼接或逐词音频数组（可缓存到 `uploads/tts-cache/`，同词不重复生成）

- **前端兜底**：edge-tts 微服务不可用时，降级用浏览器 **Web Speech API**（`speechSynthesis`）发音——保证离线/服务挂时训练不中断。

- ⚠️ 注意：edge-tts 依赖微软在线服务，需环境可联网；首词生成有 1~3s 延迟 → **预生成下一组音频**（在当前组播放期间后台生成下组）消除等待。

## 五、AI 词汇老师（短语填空题，实时出题）

- 新增 `SubjectInstruction`：`subject='词汇老师'`，`systemPrompt` 如下（**只做出题，不做任何其他行为**）：

```
你是一位严谨的初中英语词汇老师。你的唯一职责：根据给定的一组单词，出 1-2 道「短语/搭配填空题」，
帮助学生把这些单词用进真实语境，加深记忆。规则：
1. 只输出 JSON 数组，格式：
   [{"sentence":"My father bought me a ____ (bike) for my birthday.","answer":"bike","hint":"单词：bike；首字母 b"},
    …]
2. 每道题的题干必须是一个英文句子，空位用 ____ 表示，括号里给出目标单词提示；
3. 只使用给定单词，不要自创单词；每道题对应一个给定单词；
4. 题目数量 = 给定单词数量（单词少时可出搭配题）；
5. 不做任何其他行为：不讲解、不评价、不寒暄、不输出题目以外的任何文字。
```

- 出题链路：`cloze` 接口把本轮已学单词列表 + systemPrompt（词汇老师指令）→ `aiServiceManager.callAI`（指定词汇老师 provider，无则默认故障转移）→ 校验 JSON → 返回前端展示；学员作答后 `cloze/check` 判定（单词比对 + LLM 辅助）。

- **不计入题库、不计入错题本、不计入学情**：短语填空题是"加深记忆"的实时互动，答案仅用于当场反馈，落库仅存 `WordSession` 的 `clozeStats`（对错统计，可选）。

## 六、艾宾浩斯记忆曲线（简化落地版）

严格艾宾浩斯需要跨天日历排程（复杂度高），建议第一阶段用**"分层复习 + 间隔重现"的简化版**，第二阶段再加跨天提醒：

1. **掌握层级 level（0-7）**：新词 level=0；答对一次 +1（上限 7）；答错重置为 1。
2. **复习间隔（按层级，艾宾浩斯档位）**：level 1→2：10 分钟；2→3：1 天；3→4：2 天；4→5：4 天；5→6：7 天；6→7：15 天。`nextReviewAt = lastCorrectOrWrong + interval`。
3. **抽词优先级**（每次训练选 roundSize=20 个）：

   - 第一优先级：`nextReviewAt <= now` 的到期错词（按 overdue 程度排序，最多占 50%）

   - 第二优先级：level=0 的新词（顺序/随机按配置）

   - 不足时补低 level 词
4. **同次训练内**：答错的词**隔 1\~2 组后再次出现**（间隔重现，加深即时记忆）。
5. **单词错题集**：`WordMistake` 按 wrongCount 降序展示；复习入口可"只练错词"。

> 跨天复习提醒（如"今天有 30 个到期词"）作为后续增强，不在首版。

## 七、前端设计

- **任务中心**：专项攻克区新增「英语单词」独立版块卡片（图标/徽标区分）：

  - 列表项：模式（听写/默写）+ 阶段 + 组数/间隔摘要；未完成显示"到期复习词 N 个"角标（可选）

  - 「新建单词任务」表单：模式 / 阶段 / 抽词 / 每组词数（1-5）/ 每组间隔秒 / 每轮词数（默认 20）——老师固定 AI 词汇老师

- **训练页 WordTraining**（独立路由 `/student/word-training/:taskId`）：

  - 顶部：进度（第 X 组/共 Y 组，本次第 N/20 词）

  - 听写：显示"第 1 组"，点击/自动播放该组单词发音（edge-tts 音频，逐个播放，组内间隔 2s）；学员输入单词 → 提交 → 判定对错 → 下一词

  - 默写：按组显示中文释义 → 学员输入对应英文单词

  - 组间隔：上一组完成后倒计时（intervalSec）自动进入下一组

  - 完成 20 词 → 自动进入"短语填空"环节（AI 词汇老师出题，逐题作答即时反馈）→ 结束 → 汇总页（正确率/错误词列表）

- 暗色主题，与现有学员端一致。

## 九、需要你确认的问题

1. **词量**：PDF 实测 **1487 个去重单词**（非 3500——该 PDF 实际收录数），是否以此为准导入？（"3500"是宣传口径，若需要补足到 3500 需另找词表）
2. **音标**：PDF 音标约 1% 缺失、少量粘接破损（如 chocolate 的音标）。**听写用发音不依赖音标**；破损音标直接置空展示，可接受吗？
3. **每次训练词数**：默认 20 个触发一轮短语填空，做成**任务可配置**（1-50 滑块）还是固定 20？
4. **听写音频**：edge-tts 需**联网**（微软服务）。若部署环境不能联网，仅靠浏览器 Web Speech 兜底（音质一般）可以吗？确认后我按"edge-tts 优先 + Web Speech 兜底"实现。
5. **艾宾浩斯范围**：首版做"分层复习 + 组内间隔重现 + 到期优先抽词"（无跨天日历提醒）；跨天"今日到期复习"提醒放第二版，可以吗？
6. **入口范围**：单词任务**学员自建 + 家长代建**都支持？（现有专项任务两侧都有创建入口，单词沿用）
7. **词表 JSON 提交仓库**：清洗后 JSON（约 150KB）提交到仓库 ✓；原始 PDF（1.4MB）不提交，只留本地题库目录，对吗？
8. **完成 20 词后**：是**强制**进入短语填空，还是可跳过（按钮"跳过直接结束"）？

确认后按第 八 节顺序实施。
