# 学员积分获得算法分析

## 概述

学员通过完成训练任务获得积分，积分计算基于多个因素的综合评估，包括正确率、题目难度和答题速度。

## 积分计算公式

### 核心算法

位置：`backend/src/services/studentTrainingService.ts` 的 `calculatePoints()` 方法

```typescript
private calculatePoints(answers: any[]): number {
  if (answers.length === 0) return 0;

  // 1. 计算正确率
  const correctCount = answers.filter(a => a.isCorrect).length;
  const correctRate = correctCount / answers.length;

  // 2. 计算平均难度
  const avgDifficulty = answers.reduce((sum, a) => sum + (a.question?.difficulty || 3), 0) / answers.length;

  // 3. 计算平均用时（秒）
  const avgTimeSpent = answers.reduce((sum, a) => sum + a.timeSpent, 0) / answers.length;

  // 4. 基础分 = 正确率 * 100
  let points = correctRate * 100;

  // 5. 难度加成：难度越高，加成越多
  points *= (1 + (avgDifficulty - 3) * 0.1);

  // 6. 速度加成：用时越短，加成越多（标准用时为 60 秒）
  if (avgTimeSpent < 60) {
    points *= (1 + (60 - avgTimeSpent) / 60 * 0.2);
  }

  return Math.round(points);
}
```

## 计算步骤详解

### 1. 基础分计算

**公式**: `基础分 = 正确率 × 100`

- 正确率 = 答对题目数 / 总题目数
- 基础分范围：0-100 分

**示例**：
- 10 道题答对 8 道：基础分 = 0.8 × 100 = 80 分
- 10 道题答对 10 道：基础分 = 1.0 × 100 = 100 分
- 10 道题答对 5 道：基础分 = 0.5 × 100 = 50 分

### 2. 难度加成

**公式**: `难度系数 = 1 + (平均难度 - 3) × 0.1`

- 题目难度范围：1-5
- 基准难度：3（中等难度）
- 每提高 1 个难度等级，加成 10%

**难度系数表**：

| 平均难度 | 难度系数 | 说明 |
|---------|---------|------|
| 1 | 0.8 | 简单题目，扣减 20% |
| 2 | 0.9 | 较简单，扣减 10% |
| 3 | 1.0 | 中等难度，无加成 |
| 4 | 1.1 | 较难，加成 10% |
| 5 | 1.2 | 困难，加成 20% |

**示例**：
- 基础分 80，平均难度 4：80 × 1.1 = 88 分
- 基础分 80，平均难度 5：80 × 1.2 = 96 分
- 基础分 80，平均难度 2：80 × 0.9 = 72 分

### 3. 速度加成

**公式**: `速度系数 = 1 + (60 - 平均用时) / 60 × 0.2`

- 标准用时：60 秒/题
- 仅当平均用时 < 60 秒时才有加成
- 最大加成：20%（用时为 0 秒时，理论值）

**速度系数表**：

| 平均用时(秒) | 速度系数 | 加成比例 |
|------------|---------|---------|
| 60+ | 1.0 | 无加成 |
| 50 | 1.033 | +3.3% |
| 40 | 1.067 | +6.7% |
| 30 | 1.1 | +10% |
| 20 | 1.133 | +13.3% |
| 10 | 1.167 | +16.7% |

**示例**：
- 基础分 88（已含难度加成），平均用时 30 秒：88 × 1.1 = 96.8 ≈ 97 分
- 基础分 88，平均用时 70 秒：88 × 1.0 = 88 分（无速度加成）

## 积分发放流程

### 1. 完成训练会话

位置：`backend/src/services/studentTrainingService.ts` 的 `completeSession()` 方法

```typescript
async completeSession(sessionId: string, studentId: string) {
  // 1. 验证会话
  const session = await prisma.trainingSession.findUnique({
    where: { id: sessionId },
    include: {
      task: true,
      answers: {
        include: {
          question: true,
        },
      },
    },
  });

  // 2. 计算积分
  const points = this.calculatePoints(session.answers);

  // 3. 使用事务管理器完成任务（包含状态更新和积分发放）
  await completeTaskTransaction(sessionId, points);

  return {
    success: true,
    points,
    sessionId,
  };
}
```

### 2. 事务处理

位置：`backend/src/utils/transaction.ts` 的 `completeTaskTransaction()` 函数

```typescript
export async function completeTaskTransaction(
  sessionId: string,
  pointsEarned: number
): Promise<void> {
  await TransactionManager.execute(async (tx) => {
    // 1. 获取会话信息
    const session = await tx.trainingSession.findUnique({
      where: { id: sessionId },
    });

    // 2. 更新训练会话状态
    await tx.trainingSession.update({
      where: { id: sessionId },
      data: {
        status: 'COMPLETED',
        progress: 100,
        completedAt: new Date(),
      },
    });

    // 3. 更新任务状态
    await tx.task.update({
      where: { id: session.taskId },
      data: {
        status: 'COMPLETED',
        completedAt: new Date(),
      },
    });

    // 4. 获取当前积分余额
    const latestTransaction = await tx.pointsTransaction.findFirst({
      where: { studentId: session.studentId },
      orderBy: { createdAt: 'desc' },
    });

    const currentBalance = latestTransaction?.balance || 0;

    // 5. 发放积分
    await tx.pointsTransaction.create({
      data: {
        studentId: session.studentId,
        amount: pointsEarned,
        type: 'TASK_COMPLETE',
        relatedId: session.taskId,
        balance: currentBalance + pointsEarned,
      },
    });
  });
}
```

### 3. 事务特性

- **原子性**：所有操作要么全部成功，要么全部失败
- **一致性**：确保积分余额正确计算
- **隔离性**：使用数据库事务避免并发问题
- **持久性**：数据持久化到数据库

## 优化建议

### 1. 当前算法的优点

✅ **多维度评估**：综合考虑正确率、难度、速度
✅ **激励机制**：鼓励学员挑战高难度题目
✅ **效率奖励**：奖励快速准确的答题
✅ **公平性**：基于客观数据计算

### 2. 可能的改进方向

#### 改进 1：调整难度加成比例

**当前问题**：简单题目扣分可能打击学员积极性

**建议**：
```typescript
// 修改难度系数计算
// 当前：1 + (avgDifficulty - 3) * 0.1
// 建议：Math.max(0.9, 1 + (avgDifficulty - 3) * 0.1)
// 效果：最低难度系数为 0.9，避免过度扣分
```

#### 改进 2：增加连续答对奖励

**建议**：
```typescript
// 计算连续答对的最长序列
let maxStreak = 0;
let currentStreak = 0;
for (const answer of answers) {
  if (answer.isCorrect) {
    currentStreak++;
    maxStreak = Math.max(maxStreak, currentStreak);
  } else {
    currentStreak = 0;
  }
}

// 连续答对加成
if (maxStreak >= 5) {
  points *= (1 + maxStreak * 0.01); // 每连续答对 1 题加成 1%
}
```

#### 改进 3：首次尝试奖励

**建议**：
```typescript
// 检查是否首次完成该任务
const previousAttempts = await prisma.trainingSession.count({
  where: {
    taskId: session.taskId,
    studentId: session.studentId,
    status: 'COMPLETED',
  },
});

if (previousAttempts === 0) {
  points *= 1.1; // 首次完成加成 10%
}
```

#### 改进 4：时间段奖励

**建议**：
```typescript
// 在特定时间段完成任务有额外奖励
const hour = new Date().getHours();
if (hour >= 6 && hour < 8) {
  points *= 1.05; // 早起学习加成 5%
}
```

#### 改进 5：进步奖励

**建议**：
```typescript
// 与上次成绩对比
const lastSession = await prisma.trainingSession.findFirst({
  where: {
    studentId: session.studentId,
    status: 'COMPLETED',
  },
  orderBy: { completedAt: 'desc' },
  include: { answers: true },
});

if (lastSession) {
  const lastCorrectRate = lastSession.answers.filter(a => a.isCorrect).length / lastSession.answers.length;
  if (correctRate > lastCorrectRate) {
    const improvement = correctRate - lastCorrectRate;
    points *= (1 + improvement * 0.5); // 进步加成
  }
}
```

## 总结

当前的积分计算算法是一个**多维度、激励导向**的系统，能够：

1. ✅ 公平地评估学员表现
2. ✅ 激励学员挑战高难度题目
3. ✅ 奖励高效的学习行为
4. ✅ 通过事务确保数据一致性

建议根据实际使用情况和学员反馈，适当调整各项系数，以达到最佳的激励效果。
