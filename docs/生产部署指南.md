# 生产部署指南（zhixue-engine-pro）

> 适用于全新服务器首次部署与日常升级。核心变化：**数据库初始化改用 `prisma db push`**（不再用 `migrate deploy`），后端容器启动时自动完成初始化。

## 一、首次部署（全新服务器）

### 1. 准备

- 服务器安装：Docker + Docker Compose、Git
- 准备 `.env`（见下节），含数据库/Redis 强密码与域名配置

### 2. 拉取代码并配置

```bash
git clone <repo-url> && cd zhixue-engine-pro
cp .env.example .env   # 或按下方模板创建
```

`.env` 关键项：

```ini
POSTGRES_USER=training_user
POSTGRES_PASSWORD=<强密码>
POSTGRES_DB=training_platform
REDIS_PASSWORD=<强密码>
VITE_API_BASE_URL=/api          # 前端经 Nginx 同域反代，保持相对路径
```

### 3. 启动（一条命令）

```bash
./deploy.sh start        # 等价于 docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
```

后端容器入口 `docker-entrypoint.sh` 会自动按顺序完成：

1. **`prisma db push`**：全量同步数据库结构（建表/枚举/索引）。幂等，秒级。
   > ⚠️ 为什么不用 `migrate deploy`：本仓库历史 schema 演进依赖 db push，migration 链不完整
   > （曾缺 SpecialTaskType/OcrMethod 枚举、ocr_providers 表），migrate deploy 会在中途失败。
2. **首次种子**（仅当库为空时）：
   - 教材体系：206 套教材 / 842 单元
   - 单词词库：初中 1273 + CET4 4011
3. 启动后端 `node dist/index.js`

### 4. 验证

```bash
curl http://localhost/health                 # 后端健康（经 Nginx）
./deploy.sh status                           # 各服务健康状态
```

### 5. 日常管理（启 / 停 / 重启）

```bash
./deploy.sh start      # 启动 / 升级（构建并 up -d）
./deploy.sh stop       # 停止全部服务并释放端口（保留数据卷，可随时 start 恢复）
./deploy.sh restart    # 重启
./deploy.sh status     # 服务状态
./deploy.sh logs       # 实时日志
```

> `stop` 执行 `docker compose down`：停止容器即释放端口；**数据卷保留**（数据库/Redis 数据不丢），再次 `start` 即可恢复。

## 二、升级部署（已有数据）

```bash
git pull
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
```

- 后端重启时自动 `prisma db push` 增量同步（只加不改，不动已有数据）
- 种子幂等：库非空自动跳过

## 三、TTS 离线音频数据包（可选，强烈建议）

发音优先读本地文件，**不依赖 AI 实时生成**（零延迟）：

```bash
# 1. 下载数据包（初中 / CET4 分开，按需）→ 解压到 backend/tts_data
#    目录结构：backend/tts_data/en-US-AriaNeural/{初中|CET4}/*.mp3
# 2. 挂载进容器（docker-compose.prod.yml 的 backend.volumes 加）：
#   - ./backend/tts_data:/app/tts_data:ro
```

未命中文件时自动降级：实时生成（edge-tts 微服务）+ 写回本地补全。

## 四、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `type "SpecialTaskType" does not exist` / `OcrMethod` | 旧 migration 链缺陷。已加 `20260110000000_ensure_core_enums` 补枚举 + 入口 db push；**直接 `npx prisma db push` 即可修复存量库** |
| `relation "ocr_providers" does not exist` | 同上一类 db push 遗留，`prisma db push` 自动补表 |
| 后端启动报 `.prisma/client` 找不到 | 构建后未 generate：`npx prisma generate`（Dockerfile 已含） |
| Redis 未启动报错 | redis 容器未起；后端有有限重连，Redis 不可用自动降级 |
| 单词无发音 | 未装 TTS 数据包且 8010 微服务未部署 → 前端 Web Speech 兜底。建议部署 word-tts 微服务（services/word-tts，`uvicorn app:app --port 8010`）或解压数据包 |

## 五、生产数据初始化补充（手动）

容器自动初始化失败或需重跑时：

```bash
docker compose -f docker-compose.prod.yml exec backend sh -c "
  npx prisma db push --skip-generate &&
  node scripts/seed-textbooks-papers.mjs &&
  node scripts/import-words.mjs seed-data/words-stage-初中.json 初中 &&
  node scripts/import-words.mjs seed-data/words-stage-CET4.json CET4
"
```
