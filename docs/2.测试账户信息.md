## 重建测试数据

如果需要重建测试数据，按顺序运行以下命令：

```bash
# 1. 运行数据库迁移（如果数据库为空）
npx prisma migrate deploy

# 2. 创建基础测试账户
npx tsx scripts/seed-test-data.ts

# 3. 创建学情概览测试数据
npx tsx scripts/seed-overview-test-data.ts
```

## 注意事项

1. 所有测试账户的密码都是 `password123`
2. 测试数据会保留在数据库中，不会自动清理
