## 🔐 登录系统

### 首次登录

1. 打开浏览器，访问平台地址
2. 在登录页面输入管理员账号和密码
3. 点击"登录"按钮
4. 登录成功后，您将进入管理员仪表盘

### 修改密码

1. 点击右上角头像
2. 选择"个人设置"
3. 在"安全设置"中修改密码
4. 输入当前密码和新密码
5. 点击"保存"

## 👥 用户管理

### 查看用户列表

1. 在左侧菜单点击"用户管理"
2. 用户列表显示所有注册用户
3. 可以按角色筛选（管理员/家长/学员）
4. 支持按用户名搜索

### 创建新用户

1. 在用户管理页面点击"创建用户"按钮
2. 选择用户角色：
   - **管理员**：拥有所有管理权限
   - **家长**：可以管理子女学习
   - **学员**：学习平台的使用者
3. 根据角色填写相应信息：

**创建管理员**：
- 用户名（必填，3-20个字符）
- 密码（必填，至少8个字符）
- 邮箱（可选）
- 手机号（可选）

**创建家长**：
- 用户名（必填）
- 密码（必填）
- 邮箱（必填）
- 姓名（选填）
- 性别（选填）
- 联系方式（选填）
- 家庭住址（选填）
- 从事行业（选填）

**创建学员**：
- 用户名（必填）
- 密码（必填）
- 授权码（必填，需要有效的未使用授权码）
- 姓名（必填）
- 性别（必填）
- 出生年月（必填）
- 年级（必填，从标准化年级选单中选择）
- 就读院校（选填）
- 学习基础（选填，薄弱/一般/良好/优秀）
- 兴趣爱好（选填）

4. 点击"确认创建"
5. 系统将自动生成用户ID
6. **学员用户会自动生成学号**（格式：STU+年份后两位+6位流水号，如STU26000001）

💡 **提示**：
- 学员注册需要消耗一个授权码
- 学号自动生成，全局唯一，不可修改
- 创建成功后请记录初始密码并告知用户

### 编辑用户信息

1. 在用户列表中找到目标用户
2. 点击"编辑"按钮
3. 根据用户角色修改信息：

**编辑管理员**：
- 仅可修改密码
- 其他信息不可修改（安全考虑）

**编辑家长**：
- 可修改邮箱、姓名、性别、联系方式、家庭住址、从事行业
- 可修改密码
- 用户名不可修改

**编辑学员**：
- 可修改年级、就读院校、学习基础、兴趣爱好
- 可修改密码
- **不可修改**：学号、账户名、姓名、性别、出生年月（核心身份信息）

4. 点击"保存"

⚠️ **注意**：
- 学员的核心身份信息创建后不可修改
- 学号是学员的唯一标识，永久不变
- 修改密码后，用户需要使用新密码重新登录

### 锁定/解锁用户

1. 在用户列表中找到目标用户
2. 点击"锁定"按钮
3. 确认操作
4. 被锁定的用户将无法登录系统
5. 点击"解锁"可恢复用户访问权限

### 删除用户

⚠️ **注意**：删除用户是不可逆操作，请谨慎操作！

1. 在用户列表中找到目标用户
2. 点击"删除"按钮
3. 在确认对话框中输入用户名确认
4. 点击"确认删除"

## 👨‍👩‍👧 亲子关系管理

### 查看亲子关系列表

1. 在左侧菜单点击"亲子关系管理"
2. 查看所有家长与学员的绑定关系
3. 列表显示信息：
   - 家长姓名
   - 家长账户名
   - 学员姓名
   - 学员学号
   - 关系类型（父亲/母亲/监护人）
   - 绑定时间
   - 绑定状态

### 搜索和筛选关系

**按关键词搜索**：
1. 在搜索框输入家长或学员的姓名/账户名
2. 系统实时筛选匹配的关系

**按条件筛选**：
1. 按家长筛选：选择特定家长，查看其绑定的所有学员
2. 按学员筛选：选择特定学员，查看其绑定的所有家长
3. 按绑定时间筛选：查看特定时间段内建立的关系

### 查看关系详情

1. 在关系列表中点击某个关系
2. 查看详细信息：
   - 家长完整信息
   - 学员完整信息
   - 绑定时间
   - 关系类型
   - 绑定状态
   - 历史操作记录

### 解绑亲子关系

⚠️ **重要说明**：
- 解绑操作会删除亲子绑定关系
- 家长和学员的账户会被保留
- 所有历史学习数据会被保留
- 解绑后家长无法查看该学员的学习数据
- 如需恢复关系，需要重新绑定

**解绑步骤**：
1. 在关系列表中找到要解绑的关系
2. 点击"解绑"按钮
3. 系统显示确认对话框，说明解绑影响：
   ```
   解绑后：
   - 家长将无法查看该学员的学习数据
   - 家长无法为该学员发布任务
   - 家长无法审批该学员的愿望
   - 双方账户和历史数据会被保留
   ```
4. 输入确认信息（如学员姓名）
5. 点击"确认解绑"
6. 系统记录解绑操作到审计日志

### 解绑后的影响

**对家长的影响**：
- 该学员从家长的学员列表中移除
- 无法查看该学员的学情概览
- 无法为该学员发布任务
- 无法查看该学员的学习报告
- 无法审批该学员的愿望

**对学员的影响**：
- 学员账户正常使用
- 可以继续学习和完成任务
- 积分和错题本数据保留
- 可以与其他家长重新绑定

### 审计日志

所有亲子关系操作都会被记录：
1. 在关系详情页面点击"操作日志"
2. 查看历史操作记录：
   - 绑定时间和操作人
   - 解绑时间和操作人
   - 其他修改记录

## 🎓 学号与授权码管理

### 学号管理

#### 查看学号列表

1. 在左侧菜单点击"学号管理"
2. 查看所有学号及其状态：
   - 可用：未分配给任何用户
   - 已分配：已绑定到学员账户
   - 已锁定：暂时禁用

#### 分配学号

1. 在学号列表中找到可用学号
2. 点击"分配"按钮
3. 选择或搜索目标学员
4. 点击"确认分配"
5. 学号状态将更新为"已分配"

#### 锁定学号

1. 在学号列表中找到目标学号
2. 点击"锁定"按钮
3. 确认操作
4. 被锁定的学号无法被分配或使用

#### 解绑学号

1. 在学号列表中找到已分配的学号
2. 点击"解绑"按钮
3. 确认操作
4. 学号将恢复为"可用"状态

### 授权码管理

#### 查看授权码列表

1. 在左侧菜单点击"授权码管理"
2. 查看所有授权码及其状态：
   - 未使用：可用于注册
   - 已使用：已被用户使用
   - 已过期：超过有效期

#### 批量生成授权码

1. 在授权码管理页面点击"批量生成"按钮
2. 配置生成参数：
   - 生成数量（1-1000）
   - 有效期（天数）
   - 授权码前缀（可选）
3. 点击"生成"
4. 系统将生成指定数量的唯一授权码

#### 导出授权码

1. 在授权码列表中选择要导出的授权码
   - 可以按状态筛选
   - 可以全选或部分选择
2. 点击"导出 CSV"按钮
3. 选择保存位置
4. CSV 文件包含授权码、状态、有效期等信息

#### 查看授权码详情

1. 在授权码列表中点击授权码
2. 查看详细信息：
   - 授权码
   - 创建时间
   - 有效期
   - 使用状态
   - 使用者（如已使用）
   - 使用时间（如已使用）

## 📚 教材体系管理

### 查看教材树

1. 在左侧菜单点击"教材体系管理"
2. 以树形结构查看教材体系：
   ```
   人教版
   ├── 七年级
   │   ├── 数学
   │   │   ├── 第一单元
   │   │   └── 第二单元
   │   └── 语文
   └── 八年级
   ```

### 添加教材节点

1. 在教材树中选择父节点（或不选择，创建顶级节点）
2. 点击"创建教材"按钮（原"添加子节点"）
3. 填写教材信息：
   - **科目**（必填）：如数学、语文、英语
   - **教材版本**（必填）：如人教版、苏教版
   - **单元**（必填）：支持添加多个单元
     - 点击"添加单元"可以添加多个
     - 如：第一单元、第二单元
   - **备注**（可选）：教材说明
   - **关键词**（可选）：便于搜索，用逗号分隔
   - **排序序号**：控制显示顺序
4. 点击"保存"

💡 **提示**：
- 可以一次性创建包含多个单元的教材
- 单元可以后续继续添加
- 关键词有助于快速搜索和筛选

### 编辑教材节点

1. 在教材树中找到目标节点
2. 点击"编辑"按钮
3. 修改节点信息
4. 点击"保存"

### 删除教材节点

⚠️ **注意**：
- 删除节点会同时删除其所有子节点
- 如果节点被任务引用，将无法删除

1. 在教材树中找到目标节点
2. 点击"删除"按钮
3. 系统检查是否有依赖关系
4. 如果没有依赖，确认删除
5. 如果有依赖，系统会提示相关任务

### 导入教材数据

支持批量导入教材数据，大大提高工作效率。

#### 下载导入模板

1. 点击"批量导入教材"按钮
2. 点击"下载模板"链接
3. 获得Excel模板文件

#### 模板格式说明

Excel模板包含以下列：

| 列名 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 科目 | 科目名称 | 必填 | 数学 |
| 教材版本 | 版本名称 | 必填 | 人教版 |
| 单元 | 单元名称 | 必填 | 第一单元 |
| 备注 | 教材说明 | 选填 | 加减法基础 |
| 关键词 | 搜索关键词 | 选填 | 计算,基础 |

**填写示例**：
```
科目    教材版本    单元        备注          关键词
数学    人教版      第一单元    加减法基础    计算,基础
数学    人教版      第二单元    乘除法进阶    计算,进阶
语文    苏教版      第一单元    拼音学习      声母,韵母
```

#### 填写模板

1. 打开下载的模板文件
2. 按照格式填写教材数据
3. 确保必填字段不为空
4. 关键词使用逗号分隔
5. 保存文件

#### 上传导入

1. 在批量导入对话框中点击"选择文件"
2. 选择填好的Excel文件
3. 点击"开始导入"
4. 系统开始解析和验证数据

#### 查看导入结果

导入完成后，系统显示结果统计：

**成功导入**：
```
成功导入 48 条教材数据
```

**部分失败**：
```
成功导入 45 条
失败 3 条

错误详情：
- 第 3 行：缺少必填字段"科目"
- 第 7 行：缺少必填字段"教材版本"
- 第 12 行：单元名称格式不正确
```

#### 导入注意事项

⚠️ **注意**：
- 确保Excel文件格式正确（.xlsx）
- 必填字段不能为空
- 单次导入建议不超过1000条
- 导入前建议先备份现有数据
- 重复的教材会被跳过
- 导入失败的行不会影响其他行

💡 **技巧**：
- 可以先导入少量数据测试
- 使用Excel的数据验证功能减少错误
- 保留模板文件，方便下次使用

### 导出教材数据

1. 选择要导出的教材版本
2. 点击"导出"按钮
3. 选择导出格式（JSON/Excel）
4. 保存文件

## 🤖 AI 服务配置

### AI 服务商管理

#### 查看服务商列表

1. 在左侧菜单点击"AI 服务配置"
2. 查看已配置的 AI 服务商：
   - OpenAI
   - Anthropic Claude
   - 其他自定义服务商

#### 添加 AI 服务商

1. 点击"添加服务商"按钮
2. 填写服务商信息：
   - 服务商名称
   - 服务商类型（OpenAI/Claude/自定义）
   - API 密钥
   - API 端点
   - 模型名称
   - 优先级（数字越小优先级越高）
3. 点击"测试连接"验证配置
4. 点击"保存"

#### 编辑服务商配置

1. 在服务商列表中找到目标服务商
2. 点击"编辑"按钮
3. 修改配置信息
4. 点击"测试连接"验证
5. 点击"保存"

#### 调整服务商优先级

1. 在服务商列表中拖动服务商卡片
2. 或点击"上移"/"下移"按钮
3. 系统将按优先级顺序调用 AI 服务
4. 当主服务商不可用时，自动切换到备用服务商

#### 启用/禁用服务商

1. 在服务商列表中找到目标服务商
2. 点击状态开关
3. 禁用的服务商不会被调用

### 科目教学指令配置

#### 查看科目列表

1. 在 AI 服务配置页面切换到"科目指令"标签
2. 查看所有科目的教学指令配置

#### 配置科目指令

1. 选择目标科目（数学/语文/英语等）
2. 编辑 System Prompt 模板：
   ```
   你是一位经验丰富的数学老师，擅长启发式教学。
   当学生遇到问题时，不要直接给出答案，而是通过提问引导学生思考。
   ```
3. 添加示例对话：
   - 学生问题示例
   - AI 回复示例
4. 点击"保存"

#### 测试教学指令

1. 在科目指令配置页面点击"测试"按钮
2. 输入测试问题
3. 查看 AI 回复
4. 根据回复效果调整指令
5. 重新测试直到满意

## ❓ 常见问题

### 用户管理相关

**Q: 如何重置用户密码？**

A: 
1. 在用户管理页面找到目标用户
2. 点击"重置密码"按钮
3. 系统将生成临时密码
4. 将临时密码发送给用户
5. 用户首次登录时需要修改密码

**Q: 用户忘记用户名怎么办？**

A: 
1. 在用户管理页面使用邮箱或手机号搜索
2. 找到用户后查看用户名
3. 或通过"找回用户名"功能发送到用户邮箱

**Q: 如何批量导入用户？**

A: 
1. 下载用户导入模板
2. 按模板格式填写用户信息
3. 在用户管理页面点击"批量导入"
4. 上传填好的文件
5. 系统将自动创建用户

### 授权码相关

**Q: 授权码过期了怎么办？**

A: 
1. 在授权码管理页面找到过期的授权码
2. 点击"延期"按钮
3. 设置新的有效期
4. 点击"保存"

**Q: 如何查看哪些授权码未被使用？**

A: 
1. 在授权码管理页面
2. 使用状态筛选器选择"未使用"
3. 系统将显示所有未使用的授权码

**Q: 授权码可以重复使用吗？**

A: 不可以。每个授权码只能使用一次，使用后状态将变为"已使用"。

### 教材管理相关

**Q: 如何快速添加整个年级的教材？**

A: 
1. 准备教材数据文件（JSON 格式）
2. 使用"导入教材"功能批量导入
3. 或使用教材模板快速创建

**Q: 删除教材节点时提示有依赖关系怎么办？**

A: 
1. 查看依赖的任务列表
2. 先删除或修改这些任务
3. 然后再删除教材节点

**Q: 如何调整教材节点的顺序？**

A: 
1. 在教材树中拖动节点
2. 或编辑节点的"排序序号"
3. 数字越小越靠前

### AI 服务相关

**Q: AI 服务调用失败怎么办？**

A: 
1. 检查 API 密钥是否正确
2. 检查网络连接是否正常
3. 查看 API 配额是否用完
4. 查看错误日志获取详细信息
5. 尝试切换到备用服务商

**Q: 如何控制 AI 服务成本？**

A: 
1. 设置 Token 消耗预算
2. 配置告警阈值
3. 定期查看使用统计
4. 优化 Prompt 模板减少 Token 消耗

**Q: 多个 AI 服务商如何协同工作？**

A: 
1. 系统按优先级顺序调用服务商
2. 当主服务商不可用时，自动切换到备用服务商
3. 可以为不同科目配置不同的服务商

### 系统监控相关

**Q: 如何查看系统性能？**

A: 
1. 在 API 监控看板查看实时指标
2. 关注响应时间和错误率
3. 如果指标异常，查看详细日志

**Q: 收到告警通知后如何处理？**

A: 
1. 登录系统查看告警详情
2. 根据告警类型采取相应措施：
   - 错误率高：检查服务状态和日志
   - 响应慢：检查服务器资源
   - Token 超限：调整使用策略
3. 处理完成后标记告警为已处理
