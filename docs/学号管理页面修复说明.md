# 学号管理页面修复说明

## 问题描述

学号管理页面的学号列表中：
1. **关联用户显示"-"**：所有已分配学号的记录都显示"-"，无法看到关联的用户名
2. **缺少姓名字段**：列表中没有显示用户的真实姓名

## 问题原因

### 1. 前端数据结构不匹配

**问题**：前端接口定义中使用了扁平的 `username` 字段
```typescript
// 错误的接口定义
interface StudentID {
  id: string;
  studentIdNumber: string;
  status: StudentIDStatus;
  userId?: string;
  username?: string;  // ❌ 错误：后端返回的是嵌套的 user 对象
  assignedAt?: string;
  createdAt: string;
}
```

**实际后端返回**：后端返回的是嵌套的 `user` 对象
```typescript
{
  id: "xxx",
  studentIdNumber: "2024001",
  status: "ASSIGNED",
  userId: "user-id",
  user: {  // ✅ 实际是嵌套对象
    id: "user-id",
    username: "student01",
    realName: "张三",
    role: "STUDENT",
    status: "ACTIVE"
  },
  assignedAt: "2024-01-22T10:00:00Z",
  createdAt: "2024-01-20T10:00:00Z"
}
```

### 2. 后端未返回姓名字段

后端查询时没有包含 `realName` 字段：
```typescript
// 修复前
user: {
  select: {
    id: true,
    username: true,
    role: true,
    status: true,
    // ❌ 缺少 realName
  },
}
```

## 修复方案

### 1. 前端修复

#### 更新接口定义
```typescript
// 修复后的接口定义
interface StudentID {
  id: string;
  studentIdNumber: string;
  status: StudentIDStatus;
  userId?: string;
  user?: {  // ✅ 正确：使用嵌套的 user 对象
    id: string;
    username: string;
    realName?: string;  // ✅ 添加姓名字段
    role: string;
    status: string;
  };
  assignedAt?: string;
  createdAt: string;
}
```

## 相关字段说明

### User 表字段
- `username`: 用户名（登录账号）
- `realName`: 真实姓名（可选字段）
  - 家长用户：必填
  - 学员用户：通过 StudentProfile 表的 realName 字段存储

### StudentProfile 表字段
- `realName`: 学员真实姓名（必填）
- `userId`: 关联的用户ID

**注意**：学员的姓名存储在两个地方：
1. `User.realName` - 可能为空
2. `StudentProfile.realName` - 必填

当前修复使用 `User.realName`，如果需要显示学员档案中的姓名，需要进一步关联 `StudentProfile` 表。

## 进一步优化建议

### 1. 优先显示学员档案姓名

对于学员用户，优先显示 `StudentProfile.realName`：

```typescript
// 后端修改
prisma.studentID.findMany({
  include: {
    user: {
      select: {
        id: true,
        username: true,
        realName: true,
        role: true,
        status: true,
        studentProfile: {  // ✅ 关联学员档案
          select: {
            realName: true,
          },
        },
      },
    },
  },
})

// 前端显示逻辑
const displayName = studentId.user?.studentProfile?.realName 
  || studentId.user?.realName 
  || '-';
```
