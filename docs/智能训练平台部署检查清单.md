## 4. 功能测试检查

### 4.1 任务创建测试

### 4.2 训练流程测试

**诊断测试阶段**:
- [ ] 学员启动训练会话
- [ ] AI 成功生成第一道诊断题目
- [ ] 学员提交答案，获得反馈
- [ ] 完成所有诊断题目
- [ ] 会话状态转换到 PLANNING

**训练计划阶段**:
- [ ] AI 成功生成训练计划
- [ ] 训练计划包含三个阶段（基础巩固、能力提升、综合应用）
- [ ] 学员确认训练计划
- [ ] 会话状态转换到 GUIDED_TRAINING

**引导式训练阶段**:
- [ ] 基础巩固阶段题目生成正常
- [ ] 能力提升阶段题目生成正常
- [ ] 综合应用阶段题目生成正常
- [ ] 每个阶段完成后生成小结
- [ ] 所有阶段完成后准备考试

**综合考试阶段**:
- [ ] 成功开始综合考试
- [ ] AI 一次性生成所有考试题目
- [ ] AI 助手在考试期间被禁用
- [ ] 学员提交考试答案
- [ ] 会话状态转换到 COMPLETED

**训练报告阶段**:
- [ ] AI 成功生成训练报告
- [ ] 报告包含所有必需内容
- [ ] 积分正确计算并发放
- [ ] 任务状态更新为 COMPLETED

### 4.3 AI 助手测试

- [ ] 诊断测试期间 AI 助手可用
- [ ] 训练期间 AI 助手可用

### 9.2 回滚触发条件

- [ ] 定义回滚触发条件：
  - [ ] 系统错误率 > 5%
  - [ ] AI 服务失败率 > 20%
  - [ ] 用户投诉 > 10 次/小时
  - [ ] 其他关键问题

### 9.3 回滚步骤

```bash
# 1. 停止应用
pm2 stop training-platform-backend

# 2. 回滚代码
git checkout <previous-version-tag>
npm install

# 3. 回滚数据库（如需要）
npx prisma migrate resolve --rolled-back <migration-name>

# 4. 重启应用
pm2 start training-platform-backend

# 5. 验证回滚成功
curl http://localhost:3000/health
```
