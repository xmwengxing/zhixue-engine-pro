# 积分商城功能升级说明

## 功能概述

本次升级对学员积分商城进行了全面改造，主要包括：

1. **现金奖励功能**：学员可以用积分兑换现金（10积分=1元）
2. **优化审批流程**：家长审批通过后，学员需要点击确认才扣除积分
3. **图片上传功能**：支持手动上传愿望图片
4. **统一视觉风格**：现金奖励和自定义愿望使用统一的渐变卡片风格

## 数据库变更

### 新增字段

在 `wishes` 表中添加了以下字段：

```sql
-- 愿望类型（CASH: 现金奖励, CUSTOM: 自定义愿望）
type WishType DEFAULT 'CUSTOM'

-- 学员确认时间（学员点击确认兑换的时间）
confirmed_at TIMESTAMP
```

### 状态说明

愿望状态 `WishStatus` 的含义更新为：

- `PENDING`: 待审批（学员提交后等待家长审批）
- `APPROVED`: 已批准（家长审批通过，等待学员确认）
- `REJECTED`: 已拒绝（家长拒绝）
- `FULFILLED`: 已兑现（学员确认后扣除积分，完成兑换）

## 后端 API 变更

### 1. 创建愿望接口

**路由**: `POST /api/student/wishes`

**新增参数**:
```typescript
{
  type: 'CASH' | 'CUSTOM',  // 愿望类型
  description: string,       // 描述
  requiredPoints: number,    // 所需积分
  imageUrl?: string          // 图片URL（可选）
}
```

### 2. 确认愿望接口（新增）

**路由**: `POST /api/student/wishes/:id/confirm`

**功能**: 学员确认已批准的愿望，扣除积分并更新状态为 FULFILLED

**流程**:
1. 验证愿望状态为 APPROVED
2. 检查学员积分是否足够
3. 扣除积分
4. 更新愿望状态为 FULFILLED
5. 记录确认时间

## 前端功能变更

### 1. 积分商城页面布局

**左侧区域**（7列）：
- 现金奖励卡片（琥珀色渐变）
- 自定义愿望卡片（蓝色渐变）

**右侧区域**（5列）：
- 我的愿望列表

### 2. 现金奖励功能

- 点击"兑换现金"卡片打开弹窗
- 输入积分数量，自动计算现金金额（10积分=1元）
- 可选填写备注说明
- 提交后等待家长审批

### 3. 自定义愿望功能

- 点击"自定义愿望"卡片打开弹窗
- 填写愿望描述
- 设置所需积分
- 支持两种方式添加图片：
  - 上传本地图片（最大5MB）
  - 输入图片URL
- 提交后等待家长审批

### 4. 愿望确认流程

当愿望状态为 `APPROVED` 且积分足够时：
1. 愿望卡片显示进度条
2. 进度达到100%时显示"确认兑换"按钮
3. 点击按钮后弹出确认对话框
4. 确认后扣除积分，状态变为 `FULFILLED`

### 5. 视觉风格统一

- **现金奖励**：琥珀色渐变（from-amber-50 to-orange-50）
- **自定义愿望**：蓝色渐变（from-blue-50 to-indigo-50）
- 卡片使用相同的圆角、阴影和过渡效果
- 图标和按钮颜色与卡片主题色保持一致

## 使用流程

### 学员端流程

1. **提交愿望**
   - 选择愿望类型（现金/自定义）
   - 填写相关信息
   - 提交申请

2. **等待审批**
   - 愿望状态显示为"审核中"
   - 可以查看审批进度

3. **确认兑换**
   - 家长审批通过后，状态变为"待确认"
   - 积分足够时显示"确认兑换"按钮
   - 点击确认完成积分扣除

### 家长端流程

1. **查看愿望申请**
   - 在愿望管理页面查看学员提交的愿望
   - 查看愿望详情（类型、描述、所需积分等）

2. **审批愿望**
   - 选择同意或拒绝
   - 可填写审批理由
   - 提交审批结果

3. **等待学员确认**
   - 审批通过后等待学员确认
   - 学员确认后积分自动扣除

## 技术实现要点

### 1. 事务处理

学员确认愿望时使用数据库事务确保：
- 积分扣除和愿望状态更新的原子性
- 避免并发问题导致的数据不一致

### 2. 权限控制

- 学员只能查看和确认自己的愿望
- 家长只能审批绑定学员的愿望
- 所有操作都需要身份验证

### 3. 数据验证

- 前端和后端双重验证
- 积分数量、描述长度等限制
- 图片文件类型和大小限制
