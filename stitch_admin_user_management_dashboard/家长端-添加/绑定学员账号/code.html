什么是授权码？

授权码是学员在校方系统中的唯一安全凭证。通过授权码绑定，您可以实时查看孩子的学习进度、错题本及AI生成的周报。

如何获取授权码？

  • 1

    联系班主任或科任老师获取纸质授权单

  • 2

    在学员端APP的“设置-个人信息”中查看

  • 3

    关注学校官方公众号，在个人中心查询
